# ARCHIVE.EXE v0.9.2

Patch for the GitHub Pages character archive prototype.

Changes in this build:
- lorebook book indicator stays on cards when a lorebook exists;
- modal actions are split into FILES and SOURCE sections;
- missing lorebooks are explicitly shown as `LOREBOOK — NOT AVAILABLE`;
- modal adds an INTRO tab with single-message display or multi-intro accordion behavior;
- author profile link remains separate from bot source link;
- old abstract CSS growth shapes are replaced by restrained vine/overgrowth SVG details around search, catalog drawer, modal and footer;
- more quiet archive easter eggs and in-theme notice styling.

Demo bot and author URLs are placeholders.
